## Summary

`buggy/stats.py` contains:
```python
def average_score(scores):
    """Return the mean of a list of numeric scores."""
    return sum(scores) / len(scores)
```
With an empty list, `sum([])` is `0` and `len([])` is `0`, so the division raises `ZeroDivisionError` — exactly matching report.md's description of a crash on "a new quiz" that "hadn't had anyone take it yet," with a stack trace into the stats helper and a `ZeroDivisionError`, guessed to be "trying to average scores before any exist."

I wrote `candidate_test.py` (in the working directory, sibling to `report.md` and `buggy/`) with a flat `from stats import average_score` import, asserting `pytest.raises(ZeroDivisionError)` around `average_score([])`.

I copied it into `buggy/`, ran `python -m pytest candidate_test.py -v` from `buggy/`, observed:
