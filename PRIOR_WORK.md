# Prior Work

Nothing in this repository predates the competition. All BugProof source code,
benchmark cases, evaluation harnesses, tests, and evidence in this submission
were produced after the August 28, 2026 kickoff during the competition window.

I have prior public work in adjacent areas, including a security-review harness
using deterministic evidence gating and an agent-tracing SDK, available through
my public GitHub profile: <https://github.com/sergiunicoara>. No code from those
projects was copied into BugProof. The deterministic-gate idea informed the
design, and I disclose that influence here explicitly so the conceptual lineage
is on the record.

The submitted archive does not include Git history. Provenance and integrity are
instead supported by the phase-based `CHANGELOG.md`, frozen and curated agent
trajectories, source-linked evidence, and SHA-256 integrity manifests under
`evidence/final/`.

Third-party dependencies and conceptual attributions are documented separately
in `THIRD_PARTY_NOTICES.md`.
