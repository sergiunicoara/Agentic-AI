Everything the agent told you in act one had already been graded before you saw it. A second model — a judge — scores every reply on three questions: is it faithful to the real CV, is it relevant, are the facts right. Fifteen golden conversations replay on every release: fifteen for fifteen, five-point-oh average. If a change makes the agent worse, the deploy is blocked. Automatically.

S08

The tests that caught real bugs

ShotTerminal. A fully green suite — the V.O. tells the story of how it got green, which builds more trust than the checkmarks.

bash — recruiter-agent
python -m pytest tests/ -q
............                                               [100%]
12 passed, 8 warnings in 49s
V.O.
Twelve for twelve — but the interesting part is how it got there. Seven tests cover barge-in, the exact feature you saw in act one; writing them caught a real race where an already-synthesized sentence could get dropped mid-interrupt. And two tests used to fail — chasing them exposed a routing bug where every GET endpoint, health check included, silently returned the web page instead of JSON.
noteThe old failing tests weren't deleted to make the suite green — they were chased to the real bug (a route-ordering issue in server.py), fixed, and replaced with regression tests that guard against it coming back.
