04 — Evaluation

Every reply is graded before it ships

scored dimensions
  • LLM-as-a-Judge — Gemini scores faithfulness, relevancy, and factuality on every turn, anchored to a rubric that knows the agent's correct behaviors (e.g. sharing CV facts is expected, not a privacy violation).
  • Critic agent (A2A) — routes replies through an MCP tool interface for structured PASS/FAIL verdicts and concrete recommended actions, not just a number.
  • CI gate — new versions run the same golden conversations; a regression in pass rate or avg score blocks deploy.
  • WER harness — a separate TTS→STT round trip catches voice-quality regressions the text judge can't see.
